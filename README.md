This repository will allow you to play TTT (aka The Torrential Turnabout) offline. This repository is divided into nine folders, one for each part of TTT. To play the full game, you will need to download all nine folders. Do not edit file names.
The content in each is twofold: a subfolder containing all assets (music, graphics, etc) that the part uses and an .html file that will allow you to play the part in an offline browser window. No additional files or apps are needed.
To play, download the part(s) you want and run the .html. That's it!
(There's also the promo image, which worked way better when scrolling down on a webpage. Ah, well. You don't need to download that, but it does serve as a synopsis.)
